# CISCO-CCNA


CCNA Command Reference by Topic
Cisco CCNA (200-301) lab commands grouped by exam topic
How to read this guide: commands are shown in a gray cell; indented lines run inside the sub-mode of the line above. Replace sample names, IPs and passwords with your own. Commands assume Cisco IOS in global configuration mode unless a show/ping/clear command indicates EXEC mode (prefix with do inside config mode).
